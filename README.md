# 16ZATSUYO（雑用タイプ診断）

質問は大真面目、結果は会社の雑用。MBTI（16Personalities）のパロディ診断サイトです。
HTML / CSS / JS だけの静的サイトで、GitHub Pages で公開しています。

## 結果の文章を直したいとき

`results/` フォルダにある `◯◯◯◯.md`（例：`OCKM.md`）を書き換えるだけで反映されます。コードは触らなくて大丈夫です。

書き方のルールは次の3つだけです。

- `# ` で始まる行 → 結果画面の**役割名**（例：`# お茶汲み`）
- `> ` で始まる行 → 役割名の下の**キャッチコピー**
- それ以外 → **本文**としてそのまま表示されます（`## 見出し` や `- 箇条書き` も使えます）

```markdown
# お茶汲み

> 会議の潤滑油は、あなたが淹れている。

## あなたの特徴
本文……
```

## グループ名・説明文を直したいとき

16タイプは4つのグループに分かれています。グループ名・説明文・並び順は `data/groups.json` で編集できます。
結果画面・タイプ紹介ページのグループ名と、全タイプ一覧ページ（`types.html`）に反映されます。

```json
{
  "id": "uragata",
  "axes": "SP",
  "name": "裏方",
  "description": "名前が表に出ることはなくても、組織の日常を確実に回し続ける人たち。",
  "types": ["OCKM", "GJRK", "BHHC", "HNKO"]
}
```

- `name` … グループ名
- `description` … 一覧ページでグループ名の下に出る説明文
- `types` … このグループのタイプ（この順で一覧に並びます）
- グループ自体の並び順は、ファイル内の順番どおりです
- `id` … 一覧ページのリンク先（`types.html#uragata`）に使う英字の名前です。変えると古いリンクが飛ばなくなるので、基本はそのままにしてください
- `axes` … どの軸の組み合わせのグループか（メモ用。表示には使いません）

一覧ページのカードに出る役割名・キャッチコピーは、`results/◯◯◯◯.md` の `# ` の行と `> ` の行から自動で読み込みます。

## 質問を直したいとき

`data/questions.json` を編集します。1問はこういう形です。

```json
{ "id": 3, "axis": 1, "reverse": true, "text": "目立つより、陰で支えているほうが落ち着く" }
```

- `text` … 質問文
- `axis` … どの軸の質問か（1：立ち位置 / 2：進め方 / 3：関心 / 4：周囲への意識）
- `reverse` … `true` にすると「そう思う」ほど − 側（裏で支える・臨機応変・モノ・マイペース）に寄ります。+ 側の質問なら書かなくてOK
- 並び順がそのまま出題順です。各軸5問ずつにしておくと、結果のバーが正しく 0〜100% になります

## 手元で確認するとき

`index.html` をダブルクリックで開くと文章が読み込めません。フォルダでローカルサーバーを立ててください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。
